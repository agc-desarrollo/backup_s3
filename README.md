# backup-s3-system

Sistema integral de backup para carpetas locales y bases de datos con almacenamiento S3, gestionado mediante API REST.

## Inicio Rápido

```bash
npm install
copy .env.example .env   # Configurar credenciales S3, BD y token
npm start
```
